# @cristicretu/penflow

Animated handwriting renderer using Typr.js glyph contours.

## Install

```bash
pnpm add @cristicretu/penflow
```

## React Usage

```tsx
import { Penflow } from '@cristicretu/penflow/react';

<Penflow
  text="hello world"
  fontUrl="/fonts/BrittanySignature.ttf"
  quality="balanced"
  seed="demo"
/>
```
